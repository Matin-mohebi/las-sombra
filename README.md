# 🤠 لاس سومبرا (Las Sombra)

**بازی اکشن دنیای باز سه‌بعدی — جایی که خیابان‌های شهر به مرز بی‌قانون می‌رسد**

یک دنیای باز سه‌بعدی کامل در مرورگر، با ترکیب حال‌وهوای دو سبک محبوب:
شهرِ پرترافیک با ماشین‌سواری و تعقیب‌وگریز پلیس (به سبک GTA) + بیابان و شهرک غربی با اسب‌سواری و شش‌لول (به سبک وسترن‌هایی مثل Red Dead Redemption).

> ⚠️ این بازی یک اثر **اورجینال** است که با Three.js ساخته شده و از هیچ دارایی (مدل، صدا، لوگو) بازی‌های رسمی GTA یا Red Dead استفاده نمی‌کند — فقط از سبک و حال‌وهوا الهام گرفته است.

## ✨ امکانات

- 🌆 **شهر لاس سومبرا**: ساختمان‌های بلند، خیابان‌های آسفالته، پارک، پارکینگ، کلانتری، درمانگاه، اداره پست
- 🏜️ **شهرک سنگ‌سرخ**: سالون، کلانتری، مغازه اسلحه، اصطبل، کلیسا، برج آبی، واگن و بشکه — با تابلوهای فارسی!
- 🚗 **۶ نوع خودرو** (سدان، اسپرت، ون، کامیون، تاکسی، پلیس) با فیزیک رانندگی، ترمزدست، بوق، بخار و انفجار
- 🐴 **اسب‌سواری** با یورتمه و گالوپ، استقامت اسب و اسب‌های وحشی در بیابان
- 🔫 **۳ سلاح**: شش‌لول، کلت برنی، شاهین ۷۰۸ — با خشاب، ریلود، نشانه‌گیری و هدشات
- ⭐ **سیستم تعقیب ۵ ستاره**: هر جرم ستاره می‌آورد؛ پلیس پیاده و ماشین‌های گشتی با آژیر تعقیبت می‌کنند
- 🎯 **۵ مأموریت**: تحویل مرسوله، شکار جایزه‌باز، مسابقه خیابانی، دوئل غروب، فرار بزرگ
- 🌗 **چرخه کامل شبانه‌روز**: طلوع، غروب طلایی، شب پرستاره با مهتاب، چراغ‌های خیابان و پنجره‌های روشن
- 👮 **یاغی‌ها و کمپ‌ها**: کمپ‌های یاغی در بیابان، عابران پیاده، تیراندازهای دوئل
- 🗺️ **مینی‌مپ چرخان** به سبک GTA با نشانگر مأموریت‌ها و دشمن‌ها
- 🔊 **صدای کاملاً رویه‌ای (Procedural WebAudio)**: شلیک، موتور، سوت آژیر، سم اسب، باد و ملودی وسترن
- 💾 **ذخیره خودکار** پول و اسلحه‌ها (localStorage)
- 📱 **کاملاً سازگار با موبایل**: جوی‌استیک لمسی و دکمه‌های شلیک/نشانه/سوارشدن — روی اندروید و iOS در مرورگر اجرا می‌شود
- 🖥️ **ویندوز / لینوکس / مک**: کافیست مرورگر را باز کنید

## 📱 پلتفرم‌ها و نصب (PWA)

بازی یک اپلیکیشن وب پیش‌رونده (PWA) است — روی **همه پلتفرم‌ها بدون نصب** اجرا می‌شود و در صورت تمایل می‌توانید مثل یک اپ واقعی آن را نصب کنید:

| پلتفرم | روش اجرا |
|---|---|
| 🪟 **ویندوز** | باز کردن لینک در Chrome/Edge — یا از نوار آدرس دکمه «Install» برای نصب به‌صورت اپ |
| 🤖 **اندروید** | Chrome → منوی ⋮ → «افزودن به صفحه اصلی» — تمام‌صفحه و آفلاین |
| 🍎 **آیفون / آیپد** | Safari → دکمه Share ⬆️ → «Add to Home Screen» — تمام‌صفحه مثل اپ |
| 🐧 **لینوکس / مک** | هر مرورگر مدرن |

> بعد از نصب، بازی **حتی بدون اینترنت** اجرا می‌شود (Service Worker).
> برای بهترین تجربه در موبایل، گوشی را **افقی** بگیرید؛ کنترل لمسی کامل (جوی‌استیک + دکمه‌ها) دارد.

## 🚀 اجرا

پیش‌نیاز: [Node.js 20+](https://nodejs.org) یا [Bun](https://bun.sh)

```bash
# نصب وابستگی‌ها
bun install        # یا: npm install

# اجرای محیط توسعه
bun run dev        # یا: npm run dev
# → http://localhost:3000

# ساخت نسخه پروداکشن
npm run build
npm start
```

## ☁️ دیپلوی (رایگان)

**GitHub Pages (خودکار):** این ریپو یک Action آماده دارد (`.github/workflows/pages.yml`). کافیست در **Settings → Pages → Build and deployment → Source** گزینهٔ **GitHub Actions** را انتخاب کنید؛ با هر push، نسخه استاتیک بازی ساخته و روی آدرس `https://USERNAME.github.io/las-sombra/` منتشر می‌شود.

سایر راه‌ها: [Vercel](https://vercel.com) یا [Netlify](https://netlify.com) — ریپو را وصل کنید و Deploy بزنید.

## 🗂️ ساختار پروژه

```
src/
├── game/                # کل موتور بازی (بدون وابستگی به React)
│   ├── engine.ts        # هماهنگ‌کننده اصلی، آسمان، چرخه شبانه‌روز، حلقه بازی
│   ├── world.ts         # ساخت شهر، شهرک غربی، بیابان، جاده‌ها و برخوردها
│   ├── player.ts        # کاراکتر، حرکت، دوربین سوم‌شخص
│   ├── vehicles.ts      # ماشین‌ها، اسب‌ها، ترافیک، هوش مصنوعی پلیس
│   ├── combat.ts        # سلاح‌ها، گلوله‌ها، دشمن‌ها، ستاره‌های تعقیب
│   ├── missions.ts      # مأموریت‌ها
│   ├── entities.ts      # سازنده مدل‌های کاراکتر/ماشین/اسب (پروسیجرال)
│   ├── particles.ts     # سیستم ذرات GPU (آتش، دود، غبار)
│   ├── audio.ts         # صداهای سنتز‌شده با WebAudio
│   ├── hud.ts           # رابط کاربری فارسی، مینی‌مپ، منوها، کنترل لمسی
│   └── input.ts         # کیبورد + ماوس + لمس
├── components/game-mount.tsx
└── app/                 # Next.js App Router
```
